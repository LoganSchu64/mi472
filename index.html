Building a Network 

For my class MI 361 IT Networking and Security I built a simulated network on GNS3. The final result and two VLANs connected to one router. I used wireshark to ensure each host in the VLANs could ping one another.    
 

Python Game 

In my MI 250 Introduction to Coding class I created a create your own adventure style game using Python while incorporating Turtle graphics in it. The game is a simulation of the end of a baseball game and you get to choose your own destiny. There are multiple options you choose along the way that will determine whether you go home victorious or just another "what could have been". The choice is all up to you. Will you make the right choices to carry your team to victory?
